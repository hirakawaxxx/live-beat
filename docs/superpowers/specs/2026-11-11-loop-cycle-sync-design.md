## 目的

Groovepad に近い体験として、(1) パッド上の円形インジケータでループ位相を示し、(2) 新規 ON は鳴っている中で最長のループが一周するまで待って次周から入る。

## 同期ルール

- ループ長 = 各パッドの `AudioBuffer.duration`（Pulse は 4 小節 = 16 拍）
- アクティブ集合に誰もいないときの最初の ON: 次の**小節**境界から開始
- 誰かが鳴っている（または開始予約中）ときの ON: アクティブなパッドのループ長の**最大値**を周期とし、その周期の次境界から開始
- OFF: 同じ周期境界で停止（開始前なら即キャンセル）
- STOP: 即時停止（変更なし）

## 見た目

- 各パッドに円形インジケータ（SVG）
- 分割数 = ループの拍数。Pulse は 16。モバイルで潰れすぎる場合は小節マーカー（4）を強調し、拍は細い目盛りでも可
- 状態: OFF 静止 / waiting（開始待ち）/ playing（位相が進む）
- Soft Mint トークンのみ。黒ネオン禁止

## 非目標

- FX、ランダム生成、BPM 変更 UI
- ループ長が異なるキットの手動編集
