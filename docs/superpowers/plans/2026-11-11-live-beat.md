# live-beat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Soft Mint デザインの静的 PWA として、Pulse Open Loops を同梱した Groovepad 型ライブ・ループ演奏（ライブラリ → 12 パッド、A/B、録音）を Cloudflare 配信できる状態にする。

**Architecture:** `adhd-bgm` と同じく `public/` を Cloudflare Workers 静的アセットで配信する。純ロジック（拍長・量子化・パック検証）は ES modules として `public/js/` に置き `node:test` で検証する。再生は Web Audio API、録音は `MediaStreamDestination` + `MediaRecorder`。音源は Pulse の同 BPM キット 3+3 を A/B 12 パッドに束ねる。

**Tech Stack:** HTML / CSS / JS（ES modules）、Web Audio API、MediaRecorder、Service Worker、Wrangler、Node.js `node:test`

## Global Constraints

- フレームワークなし（React / Vue / Vite / Tone.js なし）
- Soft Mint トークンのみ使用（`var(--…)`）。Groovepad 黒ネオン見た目は禁止
- CSP: `default-src 'self'`（インライン script/style 禁止）
- 音源は Pulse Open Loops（CC0）のみ同梱。SampleRadar / Looperman 等は禁止
- ランダム生成・FX・レッスン・アカウント・アップロードは作らない
- パッド ON/OFF は**小節境界**（4/4、1 小節 = 4 拍）で反映
- コミットメッセージは Conventional Commits（`feat:` / `fix:` / `test:` / `chore:` / `docs:`）
- テスト実行: リポジトリルートで `node --test`
- 仕様書: `docs/superpowers/specs/2026-11-11-live-beat-design.md`

- [ ] **Step 3: Write minimal implementation**

```js
export function barDurationSec(bpm) {
  return (60 / bpm) * 4;
}

export function nextBarTime(currentTime, originTime, barDur) {
  if (barDur <= 0) throw new Error('barDur must be positive');
  const elapsed = currentTime - originTime;
  const bars = Math.ceil(elapsed / barDur - 1e-9);
  const n = Math.max(0, bars);
  return originTime + n * barDur;
}
```

（境界ちょうどで「今」を返すため、`1e-9` で浮動小数のずれを吸収する。）

- [ ] **Step 1: Write fetch script**

```js
// scripts/fetch-pulse-kits.mjs
// Downloads kit ZIPs from pulse.studiosphere.space and extracts WAVs.
// URL pattern: https://pulse.studiosphere.space/open-loops/kits/{slug}-{bpm}/download
import { mkdir, writeFile, access } from 'node:fs/promises';
import { spawnSync } from 'node:child_process';
import { join } from 'node:path';

const BPM_LIST = [96, 120, 140];
const SLUGS = [
  'copper-step', 'ember-weave', 'glass-orbit',
  'ion-bloom', 'lunar-relay', 'prism-current',
];

const root = new URL('..', import.meta.url).pathname;

async function exists(path) {
  try { await access(path); return true; } catch { return false; }
}

for (const bpm of BPM_LIST) {
  for (const slug of SLUGS) {
    const dir = join(root, 'public', 'packs', String(bpm), slug);
    const marker = join(dir, 'drums.wav');
    if (await exists(marker)) continue;
    await mkdir(dir, { recursive: true });
    const url = `https://pulse.studiosphere.space/open-loops/kits/${slug}-${bpm}/download`;
    const zipPath = join(dir, 'kit.zip');
    const res = await fetch(url);
    if (!res.ok) throw new Error(`Failed ${url}: ${res.status}`);
    await writeFile(zipPath, Buffer.from(await res.arrayBuffer()));
    const unzip = spawnSync('unzip', ['-o', zipPath, '-d', dir], { stdio: 'inherit' });
    if (unzip.status !== 0) throw new Error(`unzip failed for ${slug}-${bpm}`);
  }
}
console.log('Pulse kits ready');
```

（macOS に `unzip` がある前提。ZIP 内の WAV 名がサブディレクトリにある場合はスクリプト内で `drums.wav` 等を `dir` 直下へ移動する処理を足す。）

### Task 6: Audio engine (load + quantized toggle + stop)

**Files:**
- Create: `public/js/audio-engine.js`
- Test: 純ロジックは Task 2 で済。エンジンはブラウザ手動（自動テストなし）

**Interfaces:**
- Consumes: `barDurationSec`, `nextBarTime` from `./timing.js`
- Produces: `createAudioEngine()` →
  - `async resume(): Promise<void>`
  - `async loadPad(padId: string, url: string): Promise<void>`
  - `setBpm(bpm: number): void`
  - `togglePad(padId: string, on: boolean): void` — 小節境界で開始／停止
  - `stopAll(): void` — 即時停止・選択クリア用に全ソース停止
  - `getMasterGain(): GainNode` — 録音接続用
  - `getContext(): AudioContext`

実装要点:

```js
// create AudioContext on first resume()
// master GainNode → context.destination
// for each loaded pad: AudioBuffer
// active sources: Map<padId, { source: AudioBufferSourceNode, gain: GainNode }>
// transportOrigin = context.currentTime at first audible start (or set on setBpm/resume)
// toggle on: next = nextBarTime(ctx.currentTime, transportOrigin, barDurationSec(bpm))
//   source = ctx.createBufferSource(); source.buffer = buf; source.loop = true;
//   // align loop: source.start(next, offset) where offset = (next - transportOrigin) % buffer.duration
// toggle off: schedule gain ramp or source.stop(nextBarTime(...))
// stopAll: stop all sources now; clear map
```

ループ長は 4 小節なので `buffer.duration` はおおよそ `barDurationSec(bpm) * 4`。ずれが大きい WAV は警告を `console.warn` するだけでよい（最初の版）。

### Task 9: Recording

**Files:**
- Create: `public/js/recorder.js`
- Modify: `public/play-app.js`, `public/play.html`

**Interfaces:**
- Consumes: `engine.getMasterGain()`, `engine.getContext()`
- Produces:
  - `createRecorder(ctx, masterGain)` → `{ isSupported, start(), async stop(): Blob, clear() }`
  - UI: 録音トグル、停止後に `<audio controls>` とダウンロードリンク

```js
export function createRecorder(ctx, masterGain) {
  const supported = typeof MediaRecorder !== 'undefined';
  let dest = null;
  let recorder = null;
  let chunks = [];
  return {
    isSupported: supported,
    start() {
      if (!supported) throw new Error('MediaRecorder unsupported');
      dest = ctx.createMediaStreamDestination();
      masterGain.connect(dest);
      chunks = [];
      recorder = new MediaRecorder(dest.stream);
      recorder.ondataavailable = (e) => { if (e.data.size) chunks.push(e.data); };
      recorder.start();
    },
    stop() {
      return new Promise((resolve, reject) => {
        if (!recorder) return reject(new Error('not recording'));
        recorder.onstop = () => {
          const blob = new Blob(chunks, { type: recorder.mimeType || 'audio/webm' });
          masterGain.disconnect(dest);
          resolve(blob);
        };
        recorder.stop();
      });
    },
  };
}
```

非対応時は `#btn-record` を disabled、`status` に「このブラウザでは録音できません」。

ダウンロード:

```js
const url = URL.createObjectURL(blob);
downloadAnchor.href = url;
downloadAnchor.download = `${pack.id}-${Date.now()}.webm`;
```
